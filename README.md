# Neha

One repository, one folder per project.

| Project | What it is |
|---|---|
| [hypergro-scene-editor](hypergro-scene-editor/) | Creative editor for bank marketers: upload an Illustrator file, change words, images, colours and language, download print-ready files. |

Add a new project as a new top-level folder with its own README, and add a row here.
Secrets (`.env`, `secrets/`) and generated data (`data/`, `node_modules/`, `dist/`) are never committed; each project's `.gitignore` covers its own.
